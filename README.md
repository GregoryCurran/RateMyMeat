# RateMyMeat 🥩

Score it. Post it. Prove it.

## Deploy to Vercel

1. Push this repo to GitHub
2. Go to vercel.com → New Project → Import this repo
3. Click Deploy (no settings to change)

## Local Development

```bash
npm install
npm run dev
```

## Tech Stack

- React 18 + Vite
- Supabase (Auth, Database, Storage)
